# Design patterns for microservices
    Service discovery -> eureka
    Edge server -> gateway
    Reactive microservices -> webflux
    Central configuration -> config
    Centralized log analysis -> Elasticsearch, Fluentd, and Kibana
    Distributed tracing -> zipkin + micrometer tracing or jaeger
    Circuit breaker -> resilience4j
    Control loop -> kubernates
    Centralized monitoring and alarms -> prometheus + grafana
